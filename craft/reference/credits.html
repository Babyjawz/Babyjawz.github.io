Artwork & credits

These guides use Craft's release artwork and the documentation design shared with Adorn. They describe the Craft desktop editor and the separate recipe patch it builds for an active MO2 Skyrim profile.

Craft artwork#

The header uses the Craft wordmark from the release graphics folder. The illustrated emblem represents leather, thread and a sewing needle; the wordmark's lettering was rendered from the supplied Dumbledor font.

Shared documentation design#

The layout, Grey, Sky, Pine and Pink themes, side navigation, article contents, search and text-size controls are adapted from Adorn's documentation. Craft's browser preferences are stored separately from Adorn's.

Typeface#

Headings, navigation and controls use the same Dumbledor font file as Adorn's documentation. The typeface is credited to Graham Meade / GemFonts. The accompanying font notice is included with the site assets.

Documentation#

The maintained Craft user guide supplies the installation steps, controls, editing behaviour, patch workflow and troubleshooting pages. The site presents that guide as separate topics. The full guide is also available as a downloadable Markdown document in the page footer.
